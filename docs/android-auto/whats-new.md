Use this page to stay up to date on what's new with Android Auto and
Android Automotive OS.

## Library releases

See the [Car App](https://developer.android.com/jetpack/androidx/releases/car-app) Jetpack page for release
notes about the [Android for Cars App Library](https://developer.android.com/training/cars/apps).
